MIDAS TES WEBSITE - GITHUB PAGES UPLOAD

1. Extract this ZIP file.
2. Open your GitHub repository: https://github.com/DevCo0d3r/Midas-TES
3. Add/replace these files in the repository root:
   index.html
   about.html
   work.html
   styles.css
   Branding/ (upload the complete folder and its contents)
4. Commit the changes to the main branch.
5. GitHub Pages should redeploy automatically.

IMPORTANT:
- Keep the exact folder name Branding (capital B).
- Keep the exact filenames inside Branding.
- index.html must remain in the repository root.
- The employment enquiry link opens the visitor's email app. It does not yet save applications to a database.
